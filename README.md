# Ultimakey

**Ultimakey** — сверхлёгкий, бескомпромиссно оптимизированный автоматический переключатель раскладки клавиатуры и текстовый помощник для Windows 10/11 (с обратной совместимостью с Windows 7/8.1).

Проект вдохновлён архитектурой macOS-приложения [keyboop](https://github.com/iffuno/keyboop) и прототипом `KeyboopWin`, но полностью спроектирован и написан с нуля на **C++20** с применением демопарсинга, zero-allocation структур данных и концепции максимальной производительности (в стиле Farbrausch demoscene / `/cpp-pro`).

## ✨ Возможности

- **Интеллектуальное автопереключение:**
  - Оценка вероятностей на основе триграмм (11,400+ RU, 8,100+ EN) и быстрого поиска в сжатых словарях (163,000+ RU, 59,500+ EN).
  - Срабатывание по пробелу, Enter (pre-convert до отправки новой строки) или Tab.
  - Учёт ритма печати и антирезонансная защита (окно 1.5 с, предотвращающее дребезг при случайных переключениях).
- **Ручное переключение (Горячая клавиша):**
  - Мгновенная конвертация последнего набранного слова (по умолчанию `Pause/Break`, настраивается).
  - Циклическая конвертация выделенного текста (через UI Automation TextPattern без повреждения буфера обмена).
- **TypoFix (Автоисправление опечаток):**
  - Встроенный словарь из 5,000+ правил опечаток с мгновенным бинарным поиском.
- **Сниппеты (Text Expansion):**
  - Поддержка сокращений любой длины независимо от текущей раскладки (например, `!email` → `myname@example.com`).
- **Двойной пробел в точку (`. `):**
  - Удобный ввод знака препинания на манер мобильных ОС.
- **CapsLock Remap:**
  - Быстрое переключение раскладки по клавише `CapsLock` без фиксации верхнего регистра.
- **Аудио-отклик (CueSynth):**
  - 34-мс процедурно синтезируемый щелчок при исправлении слова, генерируемый в памяти без внешних WAV-файлов.
- **Режимы для приложений (App Modes):**
  - Индивидуальные профили: `auto`, `soft` (учет контекста/IDE) или `off` (игры, терминалы, графические редакторы).
- **Безопасность (Secure Input):**
  - Автоматическое отключение в полях ввода паролей через асинхронный опрос UI Automation.
- **Классический Win32 интерфейс:**
  - Нативное окно настроек (`SysTabControl32`), открывающееся мгновенно и не потребляющее системных ресурсов в фоне.

## 🛠 Техническая архитектура

- **Zero-Copy DAWG (Directed Acyclic Word Graph):**
  Все 220 000+ слов русского и английского языков сжаты в компактные ориентированные ациклические графы (~850 КБ суммарно). Поиск слова выполняется за \(O(L)\), где \(L\) — длина слова, без единой динамической аллокации памяти.
- **Двоичные триграммы:**
  Таблицы частотностей упорядочены по 64-битным хешам и вшиты в секцию ресурсов EXE-файла.
- **Разделение потоков:**
  Хук клавиатуры (`WH_KEYBOARD_LL`) выполняет только критически быстрые проверки. Анализ UI Automation, считывание выделения и эмуляция синтетического ввода (`SendInput`) вынесены в оптимизированные фоновые механизмы с маркером `0x4B424F4F`.
- **Конфигурация:**
  Хранится в `%APPDATA%\Ultimakey\settings.json`. Приложение само генерирует файл при первом запуске с оптимальными настройками по умолчанию.

## 📦 Сборка проекта

### Требования:
- **Компилятор:** GCC (MinGW-w64) 14+ или Clang / MSVC с поддержкой **C++20**.
- **Система сборки:** CMake 3.20+ и Ninja (или Make).
- **Python 3.10+** (требуется только для перегенерации бинарных словарей из исходных текстовых списков).

### Шаги сборки:

1. **Клонирование репозитория:**
   ```bash
   git clone https://github.com/rehan-remade/Ultimakey.git
   cd Ultimakey
   ```

2. **(Опционально) Пересборка бинарных словарей:**
   ```bash
   python tools/bake_data.py
   ```
   *(Бинарные файлы уже сгенерированы в `src/data/` и готовы к линковке).*

3. **Сборка через CMake (MinGW-w64):**
   ```bash
   cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
   cmake --build build
   ```

4. **Результат:**
   В папке `build/` будет создан полностью автономный `Ultimakey.exe` размером ~2.7 МБ, не требующий внешних зависимостей.

## ⚙️ Управление

- **Иконка в трее:**
  - **Зелёная** — автоматический режим активен.
  - **Серая** — автоматический режим выключен.
  - Клик правой кнопкой мыши открывает контекстное меню:
    - *Включить авто-режим* (вкл/выкл)
    - *Настройки...* (диалог с вкладками: Основные, Клавиши, Приложения, Сниппеты, Словарь)
    - *Журнал (Log)* (просмотр событий в реальном времени)
    - *О программе*
    - *Выход*
